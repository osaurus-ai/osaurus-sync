# Osaurus.Sync

.NET 8 bindings for the Osaurus sync core: local-first, end-to-end encrypted sync of
conversations across a user's devices.

The package ships native libraries for `win-x64` and `win-arm64`, plus `osx-arm64` for
development on a Mac, under `runtimes/<rid>/native`. .NET picks the right one at build time.

For the full API (reading, writing, subscriptions, streaming, pairing, errors), see the
[client guide](https://github.com/osaurus-ai/osaurus-sync/blob/main/docs/client-guide.md).

## Installing

Final releases are pushed to NuGet as `Osaurus.Sync`:

```sh
dotnet add package Osaurus.Sync
```

Prereleases are only attached to the GitHub release. Download the `.nupkg` into a folder and add
that folder as a package source:

```sh
gh release download v0.1.0-beta.1 -R osaurus-ai/osaurus-sync -p '*.nupkg' -D packages
dotnet nuget add source "$PWD/packages" --name osaurus-local
dotnet add package Osaurus.Sync --version 0.1.0-beta.1
```

To keep the source with the project, use a `nuget.config` next to the solution instead:

```xml
<configuration>
  <packageSources>
    <add key="osaurus-local" value="packages" />
  </packageSources>
</configuration>
```

NuGet caches packages by version, so a rebuilt package with the same version needs
`dotnet nuget locals all --clear` before it's picked up.

Prerelease DLLs aren't code-signed. Windows SmartScreen and some antivirus products may warn
about an app that loads them; final releases are signed with Authenticode.

## Quick start

```csharp
using Osaurus.Sync;

var dir = Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "Osaurus", "Sync");
using var core = OsaurusSync.Open(dir, Environment.MachineName);   // uses DpapiKeyStore

var scope = core.CreateConversation("Plans");
using var sub = core.Subscribe(scope, changes =>
{
    // Runs on the core's callback thread.
    foreach (var change in changes)
        if (change is ScopeChange.MessageAdded added)
            Dispatcher.InvokeAsync(() => Messages.Add(added.Message));
});
core.SendMessage(scope, OsaurusSync.Text("hello"));

// On shutdown:
await core.Close();
```

`OsaurusSync.Open` fills in the platform, the default network configuration and the API version.
To configure everything yourself, build a `CoreConfig` and call `SyncCore.Open(config, keyStore)`.

## API shape

The bindings are generated by [uniffi-bindgen-cs](https://github.com/NordSecurity/uniffi-bindgen-cs):

- Methods and properties are PascalCase: `core.SendMessage(...)`, `message.Content`.
- Sequences are arrays (`Message[]`).
- Records are C# records, so `with` works:
  `OsaurusSync.Text("hi") with { ReplyTo = id }`.
- Enums with data are nested record types. Match them with patterns:
  `case ScopeChange.Stream s:`, `new HistoryMode.Recent(30)`.
- Free functions are static methods on `OsaurusSyncFfiMethods`, for example
  `OsaurusSyncFfiMethods.DefaultNetworkConfig()` and `GenerateAgentSecret()`.
- `SyncCore`, `Subscription` and `OutgoingStream` are `IDisposable`. Disposing a subscription
  cancels it, and disposing an unfinished stream marks it interrupted.

## Threading

Calls are synchronous and fast, because they go to local SQLite. The exceptions are the async
methods that wait on the network: `PairWithOffer`, `FetchAttachment`, `ResolveAgent`, `Suspend`,
`Resume` and `Close`, which return `Task`.

Listener callbacks run on one dedicated thread, in order. Marshal them to the UI thread yourself,
for example with `Dispatcher.InvokeAsync`. A callback may call back into the core.

## Keys

`DpapiKeyStore` keeps the device key and the user secret as files under
`%LOCALAPPDATA%\Osaurus\Sync\keys`, each encrypted with DPAPI in `CurrentUser` scope. Only this
Windows user on this machine can decrypt them, so a copied or restored profile gets a fresh
device key. Its history is kept, and the core raises `RecoveryAvailable` until the user enters
the recovery phrase. Scope encryption keys aren't stored here; the core recovers them from the
event log using the device key or the recovery key.

Pass a directory to `new DpapiKeyStore(path)` to keep keys elsewhere. Use `MemoryKeyStore` only
in tests.

## Errors

Every failure throws a subclass of `SyncException` (`SyncException.PermissionDenied`,
`SyncException.AlreadyOpen`, and so on). `SyncErrorCode.CodeOf(e)` returns its stable numeric
code, which matches the Swift binding. Map codes to user-facing text and log the message.

```csharp
catch (SyncException e) when (SyncErrorCode.CodeOf(e) == SyncErrorCode.AlreadyOpen)
{
    // Another instance of the app owns the data directory.
}
```

## Networking

Discovery uses mDNS on the LAN and, if the app sets a discovery server and relays in
`NetworkConfig`, DNS for known devices elsewhere with relays as a fallback. For development and
beta builds, `OsaurusSyncFfiMethods.N0PublicNetworkConfig()` uses number0's public servers;
don't ship it (see [deployment](https://github.com/osaurus-ai/osaurus-sync/blob/main/docs/deployment.md)). The
first launch may show a Windows Firewall prompt for UDP on private networks. Accept it so that
devices on the same LAN can connect directly. Otherwise they connect through a relay, which
works but is slower. `core.Diagnostics()` shows whether each connection is direct or relayed.

## Logging

```csharp
SyncLogging.UseLogger(loggerFactory, LogLevel.Info);   // before opening the core
```

Attach `core.SupportBundle()` (redacted JSON with counters and recent logs) to support requests.

## Building from source

Requirements: the Rust toolchain from `rust-toolchain.toml`, the .NET 8 SDK, and
uniffi-bindgen-cs.

```sh
cargo install uniffi-bindgen-cs --git https://github.com/NordSecurity/uniffi-bindgen-cs --tag v0.11.1+v0.31.0

scripts/gen-csharp.sh                                       # host platform, release
TARGET=x86_64-pc-windows-msvc scripts/gen-csharp.sh         # a specific target
dotnet test bindings/csharp/OsaurusSync.Tests
```

`gen-csharp.sh` builds the native library, generates `OsaurusSync/Generated/osaurus_sync_ffi.cs`,
and copies the library into `OsaurusSync/runtimes/<rid>/native`.

To pack the NuGet package, put the native libraries for each runtime identifier under
`dist/native/<rid>/` (CI uploads them in this layout) and run:

```sh
scripts/pack-nuget.sh dist/native           # writes dist/nuget/Osaurus.Sync.<version>.nupkg
VERSION=0.2.0 scripts/pack-nuget.sh         # override the version
ALLOW_PARTIAL=1 scripts/pack-nuget.sh       # local smoke test without both Windows libraries
```
